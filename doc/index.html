rag-example

A minimal, modular Retrieval-Augmented Generation pipeline you can read in one sitting.

Read the tutorial (PDF, 中文) GitHub repo

Architecture

Two phases. Index once, query on every question. Each stage is its own module with a tiny interface, so any piece can be swapped without touching the rest.

pipeline.py wires it all together. Sample documents live in data/docs/ (3 files → 6 chunks with the default chunker).

Examples

Runnable scripts under examples/. Run them from the repo root after pip install -r requirements.txt.

no LLM needed

01 · Retrieve content

Pull content out of RAG: ranked chunks, similarity scores, and source metadata for a question.

python examples/01_retrieve.py
LLM required

02 · Answer with sources

Full Q&A: retrieve → build prompt → generate, with cited sources. Uses local Ollama by default.

python examples/02_answer.py
no LLM needed

03 · Your own documents

Point the pipeline at any folder of .md/.txt files instead of the samples.

RAG_DOCS_DIR=~/my-notes \
  python examples/03_my_docs.py \
  --ask "How is caching designed?"
no LLM needed

04 · Custom chunker

Inject your own chunking strategy via RAGPipeline(settings, chunker=...) — no pipeline changes.

python examples/04_custom_chunker.py

For a step-by-step walkthrough of each example — implementation, how to run, and expected output — see the tutorial PDF (Traditional Chinese, 7 pages).

Swapping components

  • Embeddings — implement the Embedder protocol (embed(texts) -> np.ndarray).
  • Vector store — replace InMemoryVectorStore with Chroma / pgvector / Qdrant behind the same add / search interface.
  • LLM — implement the LLMClient protocol (generate(system_prompt, user_prompt) -> str).
  • Chunking — implement the Chunker protocol and pass chunker=... to RAGPipeline.
